# Data Directory

This directory is intended for datasets used in SentinelRAG.

## Practical Repository Rules
1. **Permitted Data**: Only synthetic data or publicly licensed datasets may be placed here.
2. **Prohibited Data**: No confidential, customer, employer, credential, personal, or sensitive data may be used.
3. **No Attack Targets**: Do not include real attack targets or live service credentials.
4. **Git Tracking**: Large datasets must NOT be committed to Git. Small manifests or metadata may be committed later.
5. **Licensing**: Dataset licenses and sources must be recorded.
