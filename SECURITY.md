# Security Policy

## Supported Status
SentinelRAG is a research prototype under development. It is not a production service and comes with no warranty. Note the known limitation that no application currently exists during Phase 0.

## Responsible Reporting Guidance
If you discover a security vulnerability in this repository:
1. Do not test against third-party systems or public endpoints.
2. Please use GitHub Private Vulnerability Reporting if it is enabled for this repository. If not, please reach out via a private contact channel.
3. Do not disclose public exploit details for unresolved vulnerabilities.
4. We make no claim of guaranteed response time for fixing issues, as this is a personal portfolio project.
