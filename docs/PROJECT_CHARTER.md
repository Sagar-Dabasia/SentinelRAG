# Project Charter

## Objective
To build a research prototype demonstrating RAG vulnerabilities and mitigations in a reproducible, local-first environment.

## Intended Users
This project is for security researchers, AI engineers, and as a personal portfolio project demonstrating secure AI engineering.

## Scope
The project covers evaluating direct prompt injection, indirect prompt injection, retrieval poisoning, and data leakage in a local RAG setup.

## Non-goals
* Not an enterprise, production-ready product.
* Not a cloud-based service.
* No use of paid LLM APIs or cloud databases.

## Constraints
* Must remain local-first.
* Free and open-source dependencies only.
* No real personal records, secrets, or employer data.

## Success Criteria
* Demonstrable evaluation of baseline RAG vulnerabilities.
* Measurable effectiveness of layered mitigations.
* Reproducible setup.

## Evidence Standards
* Claims must be backed by reproducible test and scan results.
* Documentation must honestly reflect the implementation state (i.e. "honest prototype positioning").
