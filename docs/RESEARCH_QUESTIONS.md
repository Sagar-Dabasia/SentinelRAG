# Research Questions

These are the initial research questions for SentinelRAG. Currently, no results exist.

1. **Baseline RAG vulnerability:** How susceptible is a naive local RAG implementation to direct and indirect prompt injection?
2. **Layered mitigation effectiveness:** How much do distinct layers of defense (e.g., input scanning, safe prompt templates, output validation) reduce successful exploit rates?
3. **Utility trade-off:** What is the impact of these security mitigations on the general helpfulness and accuracy (utility) of the RAG system?
4. **Operational cost:** How much latency and compute overhead do these mitigations introduce?
5. **Later model sensitivity:** How does vulnerability change when replacing the underlying local model?
